# 相声宇宙内容规则

## 项目定位

本站将郭德纲、于谦相声中出现的人物、地点、机构、
物品、节目与荒诞事件，当成真实存在于一个平行世界中的事实，
并以现实互联网网站的形式呈现。

本站不是相声百科。

---

## 内容等级

### S1：原作确认事实

只有用户亲自确认，或已有明确可靠来源支持的内容，
才可以作为世界观事实写入。

### S2：网页结构性填充

允许 AI 自由设计：

- 导航
- 按钮
- 栏目
- 页面布局
- “暂无资料”
- “信息更新中”
- 不产生新剧情的界面文字

### S3：新增世界事实

默认禁止 AI 自行生成，包括：

- 新人物经历
- 新职业
- 新亲属关系
- 新地点
- 新历史事件
- 新数字
- 新作品出处
- 原作没有提供的具体日程

除非用户明确要求二创。

---

## 基本原则

不知道就留空。

不要为了让页面丰富而编造内容。

不同相声之间的矛盾不需要强行解释或统一。

人物、地点和机构可以自由散落在不同网站页面中，
不要求建立对应的百科栏目。

页面首先应该像现实中某种真正存在的网站，
其次才是展示相声梗。


---

## 参考材料与公开边界

参考稿、草稿和用户提供的长篇素材**不自动等于上线资产**。其中只要含有尚未由用户确认的扩写，就不得因为页面需要素材而直接提交到公开仓库或随 GitHub Pages 发布；可以只复用用户明确认可的表现形式，把未知内容留空或显示“暂无资料 / 资料整理中”。

提交前应同时检查待提交集合与文本质量：至少运行 `git diff --cached --check`，并用 `git diff --cached --stat` 复核实际将进入版本库的文件。若发现参考稿被误暂存，应只从 Git 索引中摘除并保留本地原文件，避免为了清理提交而误删用户素材。
